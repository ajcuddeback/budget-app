# Feature guides

One guide per thing a person can do. Start from [`../_TEMPLATE.md`](../_TEMPLATE.md).

Name files for the **task**, not the feature: `split-a-transaction.md` reads better and matches
what someone would search for than `transaction-splitting.md`.

Each guide is written after its slice ships — from screenshots of the real app, never from the
developer feature doc in `docs/features/`. Those describe what we meant to build; this describes
what a person will actually see.
