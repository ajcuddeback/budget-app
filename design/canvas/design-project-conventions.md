# Budget Owl — project conventions

## Every screen ships both viewports
Any screen, state, dialog, or action gets BOTH a mobile view and a desktop view.
Phone sheets and desktop dialogs are the same fields in the same order with the
same numbers — never design one without the other.

## Design system
Organic, bound at `_ds/organic-437bb626-f315-4950-9bd4-1ee673461f1a/`.
Dark mode is a first-class requirement, not an afterthought — warm near-black
ground (#1a1613 / #241e19 / #2d2620), accents step up to their 400 tints.
